Pilih unggah file Excel atau catat transaksi secara manual.

  • Unggah Excel

Unggah Excel

File harus berformat .xlsx dan berukuran maksimal 10 MB.

Progres unggah akan ditampilkan saat proses berlangsung.

Template Excel belum tersedia sebagai file pada prototype statis ini.

Validasi Data

  • Kolom wajib harus terisi.
  • Jumlah terjual harus berupa bilangan bulat positif.
  • Transaksi yang melebihi stok tersedia tidak boleh disimpan.
  • Baris yang gagal perlu dilaporkan bersama nomor baris dan alasannya.
Pratinjau laporan baris gagal

Laporan nomor baris dan alasan akan tampil setelah file divalidasi.

Pratinjau impor berhasil

Impor transaksi berhasil.
